## 1.4 对本课题的启示

1. **原子事实拆分**（FActScore、MiniCheck）是为长文本设计的。本课题的回答格式是"选项编号加一句解释"，很可能拆不出几条原子事实。这一点要作为风险在 2.3 节论证。
2. **RAGAS faithfulness** 衡量"回答里的说法是否被上下文支持"。这里的回答本质上是选一个选项，用这个指标的意义有限，而且 RAGAS 默认要调用 LLM，会产生费用。
3. TRIVIA+ 的结论（LLM-Judge 是有竞争力的基线）给了本文一个必须正面比较的对手。本文已有的结果是：在本任务上，本文方法显著优于 LLM-Judge。
4. 白盒方法（SEPs、LUMINA、INTRYGUE）需要模型的隐藏状态，DeepSeek API 拿不到。它们只能写进相关工作，或者用作"如果答题模型是本地开源模型"的讨论。
5. **"多视角一致性"和 SelfCheckGPT / Self-Consistency 同属"一致性"一类方法**。区别在于扰动的对象不同：SC 是在同一个提示词下随机采样；本文是改变**证据来源**（不检索、BM25、稠密检索）。这是本文和已有工作的界线，写相关工作时需要讲清楚。
