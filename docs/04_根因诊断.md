# 4. 第 1 轮根因诊断（探针证据）

> 依据 `要求.md` 第三节第 5 条：判定不成立的实验，要用探针数据定位根因，不能凭推测。
> 所有探针只在 **val**（seed=3407，500 题，84 个幻觉）上计算，只读缓存，不调用 API。

## E1：SLM margin 改用 logit 尺度（判定：不成立）

| 特征组 | val AUROC |
|---|---|
| slm_own（概率） | 0.694 |
| slm_margin（概率） | 0.681 |
| slm_margin（logit） | 0.705 |
| slm_argmax_agree | 0.652 |
| own + rival + margin（概率） | 0.686 |
| own + rival + margin（logit） | 0.714 |
| own + rival + margin + argmax_agree（概率，宿主 SLM-contrast） | **0.715** |
| own + rival + margin + argmax_agree（logit） | 0.714 |

- 不加 argmax_agree 时，logit 尺度确实更好：0.686 → 0.714，提升 0.028。
- `slm_argmax_agree` 与 `slm_margin_logit` 的 Spearman 相关系数为 0.86；99% 的题两者正负号一致（margin_logit > 0 ⇔ 小模型首选就是最终答案）。
- 宿主的 SLM-contrast 特征组里已经有 argmax_agree，所以 logit 尺度能带来的信息已经被它覆盖了。

**根因**：特征冗余。PLAN 里设想的"尺度未归一化"确实存在，但宿主特征组里已经有一个特征补上了这部分信息。
**修正方案**（下一轮可选）：不需要修正。论文里可以把这一点写成分析："小模型打分接近饱和时，只用 argmax 一致性就能保留大部分区分信息。"

## E2：原子事实拆分加核查（判定：加到 Ours 上不成立；加到 NLI-contrast 上成立但未达显著）

| 方法 | val | test |
|---|---|---|
| Ours | 0.852 | 0.790 |
| Ours + atomic | 0.860 | 0.787 |
| Ours，把 NLI 特征换成 atomic 特征 | 0.859 | 0.789 |
| NLI-contrast | 0.644 | 0.600 |
| 只用 atomic 特征 | 0.660 | 0.594 |

- `atomic_min` 与 `nli_own` 的 Spearman 相关系数为 0.64。
- 退回到"题目 + 所选选项"这条主张的比例为 **0%**。规则拆分总能拆出至少一条不少于 3 个词的陈述，所以 PLAN 里预先登记的"拆分失败"假设被否定。
- 每个回答的陈述数中位数是 2；54% 的回答不超过 2 条陈述（val 和 test 合计）。
- 忠实度均值：答对的题 0.628，答错的题 0.545，有差别但不大。

**根因**：拆分粒度失配（选择题的解释很短），加上与已有的 NLI 选项核验信息冗余。把 NLI 换成 atomic 后效果不变，说明两者可以互相替代，但叠加起来没有好处。
**修正方案**（下一轮可选）：没有能显著提升的方向。论文里如实报告：原子事实核查适合长文本生成（FActScore 的设定），不适合选择题这种"选项编号加一句解释"的格式。在 RAGTruth（回答较长）上的结果见 E10。

## E4：纠正（判定：成立，但未达显著）

- val：不纠正 83.2%，全部改用 BM25 视角 85.2%，按风险纠正（τ = 0.1）86.0%；与更强的基线（全部用 BM25）比，McNemar p 见 REPORT。
- test：80.8%、80.9%、81.7%，方向一致。
- 风险提示：提升主要来自"BM25 视角在这个数据集上本来就更好"。按风险只换 10% 的题，比全部换掉多出 0.8 个百分点（val）和 0.8 个百分点（test）。

## E10：RAGTruth 迁移（不设阈值，只记录结果）

test 共 2,700 条，幻觉率 34.9%；在 train 中抽 1,000 条（seed=3407）用来训练融合模型、选阈值。

| 检测器 | AUROC [95% CI] | QA / Summary / Data2txt AUROC |
|---|---|---|
| NLI-claim（原子拆分 + NLI） | 0.744 [0.726, 0.764] | 0.772 / 0.664 / 0.514 |
| SLM-verify（Qwen3-0.6B） | 0.570 [0.548, 0.592] | 0.543 / 0.565 / 0.482 |
| Fusion（逻辑回归） | 0.774 [0.756, 0.793] | 0.768 / 0.645 / 0.492 |

**探针**：
- P1：SLM 打分 P(Yes) 在 test 上的 5%、50%、95% 分位数分别为 0.986、0.9975、0.9995；93% 的回答超过 0.99。
- P2：SLM 输入超过 1,500 token 被截断的只有 2%；截断与未截断样本的 AUROC 分别为 0.598 和 0.569。截断不是原因。
- P3：Data2txt 的上下文是 JSON 格式的结构化记录，幻觉率 64.3%，三种检测器的 AUROC 都在 0.48 到 0.51 之间。

**结论**：
1. 原子事实核查在长回答上有效（RAGTruth 回答约 100 词），在 3GPP 选择题的短解释上无效（26 词）。这与 E2 的根因判断（拆分粒度失配）方向一致。
2. 小模型核验器的根因是**打分饱和**：没有可以相互比较的选项，绝对分数就失去区分能力。这说明本文方法里小模型的作用依赖"逐个选项对比"这一设计，不能直接拿去判断一整段回答。
3. Data2txt 失效的原因是 NLI 模型没有针对结构化输入训练，属于输入格式不匹配。

## E5：Self-Consistency 基线（val）

设置：沿用宿主的 RAG 提示词，temperature = 0.7，采样 K = 5 次；风险分 = 1 − 与最终答案相同的采样所占比例。

| 方法 | val AUROC |
|---|---|
| Self-Consistency（K=5） | 0.644 |
| Ours | 0.852（Ours − SC 的配对差值 95% CI 为 [+0.151, +0.269]） |

**探针**（val 500 题，只读已保存的采样结果）：
- 5 次采样完全相同的题占 86%，这些题的幻觉率为 12.3%。
- 在所有幻觉中，**63%** 是 5 次采样都给出同一个错误答案。
- 出现答案分歧的题：SC 占 14%，多视角（换证据来源）占 24%。
- 幻觉中能被发现分歧的比例：SC 为 **37%**，多视角为 **64%**。

**结论**：SC 只在同一个提示词下随机采样，模型给出错误答案时往往很笃定（temperature 0.7 下仍然高度一致），所以一致性信号很弱。多视角一致性改变的是**模型看到的证据**（闭卷、BM25、稠密检索），能暴露出"答案依赖于检索到了什么"的不稳定性。这直接支持本文"扰动证据来源，而不是扰动采样"的设计。

## E6：Telco-RAG* 领域基线（val，判定：显著低于宿主）

val 500 题：Telco-RAG* 76.4%，宿主（混合检索 + 重排）83.2%（McNemar p = 0.00077），BM25-RAG 85.2%（p = 8.0e-6）。
与闭卷 78.8% 的差异不显著（p = 0.25）。每题 3 次 LLM 调用、平均 3,812 token；实际扣费 2.07 元（余额 45.46 → 43.39）。

**探针**（val，只读缓存）：
- P1 **路由偏差**：语料中被引用最多的 38 系列（NR 无线接入）和 23 系列（系统架构），只有 16% 和 6% 的题被路由选入前 5；
  而 29 系列（固网内部信令）有 79% 的题被选入，24 系列有 60%。宿主 top-5 证据最常来自 38 系列（525 次）和 23 系列（456 次）。
  宿主证据所在系列与路由结果有交集的题只占 54%。
- P2 **证据覆盖**：正确选项的关键词被检索证据覆盖的比例（AnsHit 代理），Telco-RAG* 的 top-10 只有 26%，宿主的 top-5 有 44%。
- P3 **候选答案步骤**：40% 的题，第一次检索后 LLM 明确回答"上下文中没有相关信息"，这些题的准确率为 72.8%（其余 78.9%）。
- P4 **改写不是原因**：改写后的问题保留了原问题 80% 的关键词（中位数），保留率低于 50% 的题只占 4%。
- P5 块长：Telco-RAG* 每块 504 字符；宿主按章节切块，每块平均 1,261 字符。

**根因**：检索漏召回，来源是**路由器替换失配**。上游的 NNRouter 是一个在 OpenAI embedding 上训练的分类器；
我们按 PLAN 换成"bge-m3 计算查询与 18 个系列描述的相似度"。系列描述是一段概括性文字（例如 29 系列的描述是"固定网络内部的信令协议"），
和具体的 3GPP 问题在语义上距离都很远，相似度排序系统性地偏向少数几个描述用词宽泛的系列，把 38 和 23 这两个最重要的系列排除在外。
检索不到证据，后面的候选答案步骤就只能基于错误的上下文。

**对论文的影响**：Telco-RAG* 的结果**不代表原版 Telco-RAG 的水平**，原版的路由器是专门训练过的。论文里应写成
"在没有路由器训练数据的条件下复现 Telco-RAG 风格的流程，按系列路由会因为路由失配而损害检索"，
并引用原论文报告的数字；不能写成"本文方法优于 Telco-RAG"。
**修正方案**（下一轮可选，免费）：去掉系列路由，只保留问题改写、术语表增强和候选答案二次检索，作为消融。这只需要本地检索，再加每题 3 次 LLM 调用（val 约 2 元）。

## E8：固定长度切块对照（val，判定：不成立）

预注册假设 H8：章节切块（宿主）比固定 300 词切块的准确率高 ≥ 1 个百分点。
结果：固定切块 84.0%，章节切块 83.2%，方向相反（Δ = +0.8 个百分点，偏向固定切块）；McNemar 多对 20、多错 16，p = 0.62，差异不显著。
实际扣费 0.10 元（余额 43.39 → 43.29；DeepSeek 前缀缓存命中较多）。

**探针**（val）：
- 检索代理指标：固定切块 AnsHit@5 = 47.8%，章节切块 43.8%；AnsHit@1 分别为 31.0% 和 31.8%。
- 送给 LLM 的上下文更长：每题输入 token，固定切块 2,577，章节切块 1,832。固定切块每块固定 300 词，章节切块的中位数只有 145 词，
  所以同样的 top-5，固定切块给模型的证据多了约 40%。
- 两个类别方向一致：specifications 81.5% 对 80.9%，overview 88.8% 对 87.6%。

**根因**：H8 预设"按章节切能保持语义完整"，但在 top_k 固定为 5 的条件下，块的**长度**才是主导因素。
固定切块每块更长，top-5 覆盖的原文更多（AnsHit@5 高 4 个百分点），抵消了切断章节边界带来的损失。
这不是"切块截断导致语义破碎"，而是两种切法提供的上下文量不同，这个对照变量没有控制住。
**修正方案**（下一轮可选）：在相同 token 预算下比较两种切法（例如章节切块取 top-7，让上下文长度接近 2,577 token），把块长和切分边界两个因素分开。

## 第 2 轮修正实验（val，按 PLAN_round2.md 判定）

### R2-B：等 token 预算下比较两种切块方式（判定：两种切法相当）
章节切块 top-7（约 2,517 token）84.2%，固定切块 top-5（2,577 token）84.0%，McNemar 22 对 21，p = 1.0。
结论：E8 中固定切块略好，是因为它给模型的上下文更长，与切块边界无关。按章节切块的价值不在于准确率，而在于每块都带有"规范编号和章节"作为上下文前缀。
实际扣费：估算 0.59 元。

### R2-A：Telco-RAG* 去掉系列路由（判定：机制成立；效果成立，但未达显著）
- 证据覆盖率（AnsHit，top-10）：有路由 26.4%，去掉路由 38.4%（+12.0 个百分点，阈值 ≥ +5）。
- 候选答案步骤回答"上下文中没有相关信息"的比例：40% → 32%。
- 准确率：76.4% → 79.2%（+2.8 个百分点，阈值 ≥ 1）；与 E6 的 McNemar 检验为 45 对 31，p = 0.14，**未达显著**。
- 仍然显著低于宿主（83.2%，p = 0.027）和 BM25-RAG（85.2%，p = 0.0008）；与闭卷 78.8%、稠密检索 79.4% 没有显著差异。
- 结论：E6 的根因（路由替换失配）得到验证，去掉路由后证据覆盖率明显回升。剩下的差距对应 Telco-RAG* 的另外两个设计：块只有 500 字符，并且没有规范和章节的上下文前缀。宿主的块平均 1,261 字符，带前缀；宿主的证据覆盖率是 44%。
- 实际扣费：估算 2.06 元（余额 41.92 → 39.43，这一段包括 R2-B）。
